# 🧩 지식 탐구 낱말퍼즐 (Knowledge Crossword Puzzle)

한국어 8대 지식 영역을 아우르는 반응형 십자말풀이 웹 애플리케이션입니다.  
초급부터 마스터 단계까지 단계별 관문(Gate)을 돌파하며 어휘력과 상식을 넓힐 수 있습니다.

---

## ✨ 주요 기능 및 특징

### 1. 8대 지식 영역 & 2,480개 어휘 탑재
- **정치 (Politics)**: 헌법, 의회, 선거, 국제정치 등
- **사회 (Society)**: 법률, 복지, 환경, 언론, 노동 등
- **문화 (Culture)**: 유네스코 유산, 전통문화, 대중문화 등
- **스포츠 (Sports)**: 축구, 야구, 동계올림픽, 구기종목 등
- **한국사 (Korean History)**: 고조선부터 근현대사까지
- **세계사 (World History)**: 메소포타미아, 그리스/로마, 르네상스, 현대사 등
- **음악 (Music)**: 국악, 클래식, 현대음악, 악기 등
- **미술 (Art)**: 동양화, 서양화, 미술사조, 현대미술 등
- **총 240개 보드 사전 생성**: 각 분야별 10개 레벨 × 레벨당 3판 완료 관문 체계

### 2. 관문 승급 및 레벨 잠금 체계
- **실력 진단 테스트 (Placement Test)**: 초기 진단 결과에 따라 적정 레벨 확정 및 하위 레벨 자동 해금
- **관문 돌파 (Gate Clearance)**: 해당 레벨의 3판을 모두 통과해야 상위 레벨이 해금
- **잠금 레벨 그레이 표시**: 미해금 상위 레벨은 비활성화 및 100% 무채색 그레이로 표시

### 3. 분야 & 레벨 통합 셀렉터 (Same Row UI)
- 가로 스크롤 없이 한 줄에서 분야와 레벨을 동시에 확인
- 버튼 터치 시 위/아래로 펼쳐지는 수직 드롭다운 메뉴로 간편하게 전환

### 4. 한글 전용 가상 키패드 & 오토 포커스
- 한글 자모음 조합 및 받침 완성 시 다음 칸으로 자동 이동
- 초성 힌트, 오답 실시간 체크, 지우개, 되돌리기 등 편의 도구 제공

### 5. 가벼운 WebP 배경 이미지 & 시각 효과
- 레벨별 테마에 최적화된 저용량 WebP 배경 랜덤 적용
- 타이머, 승급 폭죽 효과(Confetti), 사운드 효과음 지원

## 🚀 시작하기

### 설치
```bash
npm install
```

### 로컬 개발 서버 실행
```bash
npm run dev
```

### 프로덕션 빌드
```bash
npm run build
```
